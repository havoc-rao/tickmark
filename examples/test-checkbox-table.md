# TickMark 测试样例：Checkbox + GFM 表格

> 用途：验证 `tickmark serve` 的 **checkbox 点击回写**、**GFM 表格渲染** 与 **表格列过滤**。
> 运行：`tickmark serve examples/test-checkbox-table.md`（或 `--no-open`），
> 在预览中点击 checkbox，观察源 md 文件是否被实时改写；
> 每个表格顶部有过滤工具栏，可统计列内取值分布（聚合计数）并多选 / 全选 / 反选 / 清空。

## 1. Checkbox（任务列表回写）

### 1.1 基础三种状态

- [ ] 未勾选（点击后变 `[x]` 并回写源文件）
- [x] 已勾选-小写 x（点击后清空为 `[ ]`）
- [X] 已勾选-大写 X（点击后清空，回写统一为小写 x / 空格）

### 1.2 不同列表前缀

* [ ] 星号前缀未勾选
* [x] 星号前缀已勾选
+ [ ] 加号前缀未勾选
+ [x] 加号前缀已勾选

### 1.3 嵌套缩进（多级）

- [ ] 一级任务
  - [ ] 二级-未勾选
  - [x] 二级-已勾选
    - [ ] 三级-未勾选

### 1.4 行内格式混合 / 边界

- [ ] **加粗** + `行内代码` + [链接](https://example.com) 混合内容
- [x] ~~删除线~~ + emoji 🎯 + 中文标点
- [ ] 空内容后缀（本行 checkbox 后无文字）
- [x]

### 1.5 负例（仅观察渲染，点击不回写）

## 4. 表格列过滤（聚合统计 / 多选 / 全选 / 反选）

> 规则速记：同列多选 = OR（并集）；跨列叠加 = AND；清空某列 = 该列筛出 0 行；
> 空单元格显示为 `(空)`；计数只统计「通过其它列过滤」的行，组合筛选时计数随其它列联动。

### 4.1 重复取值（观察聚合计数）

| 优先级 | 模块 | 负责人 | 状态 |
| :----: | ---- | ---- | ---- |
| P0 | 登录 | 张三 | 已完成 |
| P0 | 登录 | 李四 | 已完成 |
| P1 | 支付 | 张三 | 进行中 |
| P1 | 支付 | 王五 | 未开始 |
| P2 | 搜索 | 李四 | 进行中 |
| P2 | 搜索 | 赵六 | 未开始 |
| P2 | 设置 | 王五 | 已完成 |
| P3 | 设置 | 赵六 | 进行中 |

> 预期：`优先级` 列统计 P0×2 / P1×2 / P2×3 / P3×1；`负责人` 列每人均 ×2。
> 选中 `优先级 = P0` 后，其余各列的计数应联动缩小为仅剩 P0 的两行（如 `状态` 只剩 已完成×2）。

### 4.2 空单元格（显示为 (空)）

| 事项 | 备注 | 里程碑 |
| ---- | ---- | ---- |
| 需求评审 | 通过 | v1.0 |
| 接口联调 | | v1.0 |
| 灰度发布 | 通过 | |
| 全量发布 | | |

> 预期：`备注` 列应有 `(空)`×2、`里程碑` 列应有 `(空)`×2；可单独勾选 `(空)` 筛选缺失项。

### 4.3 跨列组合（AND）与列内多选（OR）

| 城市 | 季度 | 销售额 |
| ---- | ---- | ----: |
| 北京 | Q1 | 120 |
| 北京 | Q2 | 150 |
| 上海 | Q1 | 90 |
| 上海 | Q2 | 110 |
| 深圳 | Q1 | 80 |
| 深圳 | Q2 | 130 |
| 广州 | Q1 | 70 |
| 广州 | Q2 | 100 |

> 预期：`城市` 列多选「北京 + 上海」→ 4 行；再叠加 `季度 = Q1` → 2 行（北京 Q1 + 上海 Q1）；
> 清空 `季度` 列 → 0 行；对 `城市` 反选 → 深圳 / 广州共 4 行。
