# TickMark 测试样例：Checkbox + GFM 表格

> 用途：验证 `tickmark serve` 的 **checkbox 点击回写** 与 **GFM 表格渲染**。
> 运行：`tickmark serve examples/test-checkbox-table.md`（或 `--no-open`），
> 在预览中点击 checkbox，观察源 md 文件是否被实时改写。

## 1. Checkbox（任务列表回写）

### 1.1 基础三种状态

- [ ] 未勾选（点击后变 `[x]` 并回写源文件）
- [x] 已勾选-小写 x（点击后清空为 `[ ]`）
- [X] 已勾选-大写 X（点击后清空，回写统一为小写 x / 空格）

### 1.2 不同列表前缀

* [ ] 星号前缀未勾选
* [x] 星号前缀已勾选
+ [ ] 加号前缀未勾选
+ [x] 加号前缀已勾选

### 1.3 嵌套缩进（多级）

- [ ] 一级任务
  - [ ] 二级-未勾选
  - [x] 二级-已勾选
    - [ ] 三级-未勾选

### 1.4 行内格式混合 / 边界

- [ ] **加粗** + `行内代码` + [链接](https://example.com) 混合内容
- [x] ~~删除线~~ + emoji 🎯 + 中文标点
- [ ] 空内容后缀（本行 checkbox 后无文字）
- [x]

### 1.5 负例（仅观察渲染，点击不回写）

## 2. GFM 表格

### 2.1 三种对齐方式

| 左对齐 | 居中 | 右对齐 |
| :----- | :--: | -----: |
| a | b | c |
| 内容较长的单元格 | 居中内容 | 右对齐内容 |

### 2.2 表头与单元格内格式

| 功能 | 示例 |
| ---- | ---- |
| 粗体 | **重要** |
| 行内代码 | `tickmark serve` |
| 链接 | [README](../README.md) |
| 转义竖线 | 显示为 `a|b`：a \| b |
| 空单元格 | |

### 2.3 多行 / 多列 / 空单元格

| 列A | 列B | 列C |
| --- | --- | --- |
| 有值 | | 空中间 |
| | | 全空行 |
| 末行 | 竖线 \| 转义 | 尾格 |
