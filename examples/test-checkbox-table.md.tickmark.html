4. 表格列过滤（聚合统计 / 多选 / 全选 / 反选）

规则速记：同列多选 = OR（并集）；跨列叠加 = AND；清空某列 = 该列筛出 0 行； 空单元格显示为 (空)；计数只统计「通过其它列过滤」的行，组合筛选时计数随其它列联动。

4.1 重复取值（观察聚合计数）

P0 登录 李四 已完成
P1 支付 张三 进行中
P1 支付 王五 未开始
P2 搜索 李四 进行中
P2 搜索 赵六 未开始
P2 设置 王五 已完成
P3 设置 赵六 进行中

预期：优先级 列统计 P0×2 / P1×2 / P2×3 / P3×1；负责人 列每人均 ×2。 选中 优先级 = P0 后，其余各列的计数应联动缩小为仅剩 P0 的两行（如 状态 只剩 已完成×2）。
